Web Clock Privacy Policy

Effective November 28, 2026

Web Clock lets you simulate a time zone or clock in a Chrome tab. You can choose to apply the same settings to supported websites that you open in Chrome.

Data and storage

Web Clock stores your chosen time zone, clock mode, custom start time and interface language in Chrome’s local extension storage. It stores tab identifiers and their active clock settings in session storage for the duration of the browser session. All-websites mode also saves its configuration and registered clock script locally so the settings can apply when you open a page.

The extension uses tab information only to identify where to apply or remove the clock settings. It does not collect browsing history, page contents, cookies, account information or analytics. It does not send settings or browsing data to the developer, a server or a third party.

Extension permissions

  • Storage saves preferences and active clock settings on this browser.
  • Debugger runs the clock code in the selected tab and makes it available when the tab reloads.
  • Active tab and scripting update or clear the clock in an authorized tab. In all-websites mode, scripting also updates the clock in open supported pages.
  • Optional HTTP and HTTPS site access and user scripts are requested when you choose to apply settings to all websites. They let Chrome apply the clock before page scripts run. The extension releases broad site access when this mode is turned off.

Retention and deletion

Preferences remain in the browser until overwritten or the extension is removed. Closing a tab ends its tab-specific setting. Choosing Restore defaults removes the active clock settings for the selected scope. Uninstalling the extension removes its locally stored data.

Support and third parties

Web Clock has no account, payment or analytics service. Its support links open Gmail when clicked. If you choose to send an email, your email provider and the support recipient handle the information you include. Gmail’s handling of information is described in Google’s privacy policy.
