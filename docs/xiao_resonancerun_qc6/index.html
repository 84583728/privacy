Resonance Run: Offline Jumping Game

Privacy Policy

Effective date: November 8, 2026

Resonance Run: Offline Jumping Game is an offline browser game. Your game data stays in your browser profile. The extension does not send your game saves or personal information to the developer, and it has no account system, advertising, analytics, or cloud synchronization.

Data processed on your device

The game stores the information needed to play and resume: completed stages, collected items, best times, unlocked and selected appearances, inventory, equipment used in a run, and the current run's checkpoints and state. It also stores sound and motion preferences, custom trails and their names, local support-reward timers, sharing allowances, timestamps, and internal operation identifiers used to avoid duplicate rewards or lost saves.

These records are gameplay data. The extension does not request your name, email address, payment details, precise location, contacts, browsing history, or the content of other websites. A name you type for a custom trail remains part of the local trail record.

Storage and permission

The only requested extension permission is storage. It is used to save the game state and a previous valid backup in chrome.storage.local. The background worker coordinates writes between the game's popup and its own expanded tab. The extension does not use browser storage sync and does not upload saves to a server.

A separately opened web preview uses the preview site's own IndexedDB and local storage. Preview data and installed-extension data are separate. Language files, graphics and game code are bundled with the extension; music and effects are generated locally.

Backups, trail codes and clipboard

When you choose to export progress, the game creates a JSON backup on your device. When you choose a backup file to restore, it reads and validates that file locally. Custom trails can be shared as a code or a downloaded text file. These actions do not upload a file or publish it to an online community.

The game writes a trail code to your clipboard only when you ask it to copy that code. It does not read your clipboard. Backups and codes may contain game progress and user-entered trail names; you choose whether and with whom to share them.

Optional external links

If you choose the optional creator-support action, the game opens the creator's YouTube channel in a normal browser tab. The game does not append your save or gameplay identifiers to that link. YouTube may process ordinary navigation information under the Google Privacy Policy. The reward uses a local five-minute elapsed-time timer; the game does not inspect video playback, subscriptions, watch history, or a YouTube account.

Opening this hosted privacy page or a contact link is also your choice. The website host or email provider handles the resulting request or message under its own practices. Contacting the developer sends only the information you include in your message; local saves are not attached automatically.

Retention and deletion

Game data remains in your browser profile until you remove the extension's stored data or uninstall the extension. Uninstalling may permanently remove progress. The developer has no server copy and cannot recover or remotely delete a local save. Downloaded backups, exported codes, clipboard contents and copies you have shared are separate; delete those separately if you no longer want them.

For a web preview, remove that preview site's stored data in your browser to delete its local save. Closing a game window does not delete progress.

Data use

Local data is used only to provide gameplay, save and restore progress, honor settings, manage earned items, and prevent duplicate local operations. The developer does not sell game data, use it for personalized advertising, or transfer it to data brokers. Our handling of data follows the Chrome Web Store User Data Policy, including its Limited Use requirements.

Contact and changes

For questions about this policy, email e@shiplang.com. Include the extension name and your question. Please do not send sensitive information that is unnecessary to answer it.

If the extension's data practices change, this policy and its effective date will be updated. Any new data handling that requires disclosure or consent will be explained before it begins.
