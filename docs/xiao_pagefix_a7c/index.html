Character Encoding

Privacy Policy

Effective date: November 3, 2026 · Extension version reviewed: 1.3.1

Product identifier: xiao_pagefix_a7c

Character Encoding repairs the character encoding of a webpage you choose. Page decoding and encoding detection run in your browser. Account and membership features use a separate ShipLang-hosted service, as explained below.

1. Webpage information and network requests

When you request a repair, the extension accesses the selected tab's URL, downloads that page's original HTML bytes, reads encoding and language hints, and processes its text locally. It uses this information to detect or apply a character encoding and update the displayed page. The extension does not upload the page's HTML or text to the developer or ShipLang.

Repairing a page is not an offline operation: the extension makes another request to the original page URL. Chrome may include the same-origin session credentials, such as cookies, that apply to that website. Images, stylesheets and other retained page resources can also be requested from their original hosts. Those websites handle these requests under their own privacy policies.

Page content and the applied encoding are processed in the page's execution context. The extension does not save page HTML or a browsing-history database in its persistent storage. Reloading or closing the page clears its temporary execution state.

2. Information stored in your browser

The extension uses Chrome's local extension storage, not its browser-sync storage, for the following purposes:

CategoryInformation and purpose
Account and membershipThe account information returned by the hosted service is stored locally. The extension reads the product identifier, account email and membership expiration to identify the product and determine access. Other fields returned in that account response can also be stored.
Trial usageA count of successful trial repairs and any pending repair task, including a generated task identifier, tab identifier and whether it counts toward the trial. This prevents overlapping operations from using the same remaining trial allowance.
Temporary repair resultsA task identifier, operation result and chosen encoding. Completed results are removed after the extension updates the corresponding usage record.

Account and accumulated trial records have no automatic expiration in the extension. A pending record can remain when an operation has not yet been resolved. These local records do not contain the repaired page's HTML or text.

3. ShipLang accounts, membership and checkout

When you open an account or payment flow, the extension opens a page at crx.shiplang.com. The request includes the product identifier, Chrome extension identifier, extension version and browser interface language. If an account is already stored, it also sends the account email and locally recorded membership expiration. The email and membership expiration are sent as URL query parameters to that service.

The service can return account and membership information to the extension for local storage and access checks. Normal connection information, such as the requesting IP address and requested URL, is visible to the service handling the request. Page content being repaired is not included in this account request.

The hosted sign-in implementation uses Google to obtain the account's email and basic profile information, such as name and avatar, and uses a callback hosted at login.chromeextensions.workers.dev. See the Google Privacy Policy.

The hosted service implementation also processes user, product and extension identifiers, IP address, interface language, account creation and login times, login counts, membership status, and payment-page access times and counts. Creating an order can produce a transaction record containing the account email, user and product identifiers, selected plan and price, IP address, language, order status, and creation or payment times.

For compatibility with previous memberships, the hosted payment flow may send the account email to the legacy membership service at pay.extensiondata.com to check eligibility. Hosted payment pages also include remote images from img.icons8.com and tpc.googlesyndication.com; those resource hosts receive the network requests needed to load those images. The presence of these images alone does not establish what further processing those hosts perform.

Checkout takes place on hosted service pages; the extension itself does not implement a payment-card form. The service supports PayPro Global, Stripe and Paddle routes. The provider actually used depends on the plan and checkout presented to you; listing these routes does not mean that every purchase is sent to all providers. When offered and used, the relevant provider policy applies: PayPro Global Privacy Policy, Stripe Privacy Policy, or Paddle Privacy Policy.

ShipLang's supplied account-service policy states that login and membership records are retained until deletion is requested and that no backup of deleted account records is retained. To request account deletion, email support@shiplang.com, identify the extension by name or download link, and describe your request. Its stated processing period is seven days. This account-deletion statement does not specify the retention periods of separate operational, legacy-membership or transaction records; contact ShipLang and the relevant provider for those records. Service-side retention is separate from the extension's local browser storage.

4. Why the extension requests permissions

PermissionPurpose
activeTabTemporarily access the active webpage after your interaction with the extension, so the requested page can be inspected and repaired.
scriptingRun the bundled encoding detector and repair code in the selected tab, read encoding information, and update that page's display.

The reviewed version does not request persistent host permissions and does not install an always-running content script across websites. It does use the current tab's identifier and URL when performing a requested operation.

5. Sharing, advertising and analytics

The extension's reviewed code contains no advertising or analytics SDK and no mechanism for selling personal information. It does not transmit repaired webpage content or a browsing-history collection to the developer or ShipLang. Network requests to the original website, retained resource hosts and ShipLang are described above. This statement does not imply that those separate services keep no connection or operational logs.

6. Your choices and deletion

You control which webpage to repair. You can reload the page to restore the website's original display, and you can stop extension processing by disabling or removing the extension.

To remove local account and usage records, clear the extension's local storage through Chrome's extension tools or uninstall the extension. This version has no built-in account-deletion or local-storage reset button. Removing local data does not delete an account held by ShipLang or records held by a payment or identity provider; request service-side deletion from the relevant provider.
