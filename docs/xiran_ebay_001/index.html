Privacy Policy

eBay Listing Image Downloader

Effective date: 2026-11-16

This policy describes the extension identified by the developer application ID xiran_ebay_001. It is an independent tool and is not affiliated with or endorsed by eBay Inc.

What the extension processes

When you click the extension on a supported eBay listing, it reads the current page URL, listing identifier, listing title, and publicly exposed product image and direct video URLs. It uses these values to show previews, let you select files, and save your chosen media. It does not read account credentials, payment information, orders, messages, or the contents of unrelated tabs.

Local storage

The extension stores the most recent download job and the selection for the most recently used listing in Chrome local extension storage. These records may contain the listing title and URL, selected media URLs, file names, download IDs, completion states, timestamps, and technical error messages. They are kept on your device and are not synchronized through a developer server or Chrome Sync by this extension. Starting a new job or selecting another listing replaces the corresponding prior record.

Files are saved through Chrome's download manager to your configured download location, usually inside a folder named for the listing. Closing the extension popup does not cancel an active download. Chrome maintains its own download records separately.

Network requests and recipients

Image previews and downloads request media directly from eBay-controlled media hosts, including ebayimg.com, ebaystatic.com, and ebay.com subdomains. These requests necessarily disclose your IP address and the browser's ordinary network request information to the receiving host. Normal browser networking, cookie, proxy, and site privacy settings apply. The extension does not send listing contents, selections, or download history to its developer, an analytics service, an advertising service, or an account or payment backend.

The example link opens an eBay search page. The support link opens a Gmail compose page addressed to the developer; Google receives the normal request information when you choose to open that link. The extension does not send email automatically. Information you voluntarily include in a support email is used to respond to your request.

Permissions

  • activeTab: temporary access to the active tab after you invoke the extension, so it can recognize a supported listing.
  • scripting: runs the bundled gallery-reading code in that authorized tab.
  • downloads: starts downloads, checks the status of download IDs created by this extension, and opens the downloads folder. If an extension-created file is identified as an invalid media type, the extension removes that incorrect file rather than reporting it as a successful download.
  • storage: retains the latest job and listing selection locally so the popup can recover them when reopened.

The extension does not request permanent access to all websites and does not load remotely hosted executable code.

Accounts, payments, and tracking

This version has no account system, payment SDK, analytics, or advertising trackers. It does not sell personal data or use listing data for advertising, creditworthiness, or purposes unrelated to downloading the media you select.

Retention and deletion

You can remove local extension records by removing the extension in Chrome. Downloads and Chrome's own download history are separate: remove them using your operating system and Chrome's download controls if desired. Removing the extension does not delete the media files you chose to keep. Technical records from the older login and payment integration are removed from local extension storage when the updated extension is installed.

The developer does not operate a server containing your listing selections or download history. If you contact support, email messages remain with the email service until deleted through that service's controls. Contact the developer if you want support correspondence deleted.

Third-party services and this policy page

Your use of eBay, Google, and the service hosting this page remains subject to their own policies. This policy page is hosted on GitHub Pages; GitHub may process ordinary visitor request information. The page contains no external scripts, fonts, or tracking resources.
