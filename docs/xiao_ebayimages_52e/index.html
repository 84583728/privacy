Privacy Policy — eBay Listing Image Downloader

Updated November 17, 2026. Developer contact: e@shiplang.com.

Listing media and local records

When you invoke the extension on an eBay product listing, it reads the listing title, URL, identifier and public gallery media URLs to display selectable previews and download the selected files. These records are processed locally, not transmitted to ShipLang or a developer analytics server. Media files are temporarily fetched and held as Blob data in a packaged hidden extension page to prepare a single ZIP archive locally. No archive is uploaded to a server. Prepared media for a failed attempt can remain available for retry until the next job or browser closure; after saving, the hidden page and its temporary media are released. Preview and download requests go directly to the relevant eBay media servers, which receive normal network information such as IP address. The extension does not read unrelated tabs or the browser history database.

Chrome local extension storage retains the latest download job and selection, including listing and media URLs, file names, download identifiers, states, timestamps and technical errors. It also retains the remaining trial allowance and a settlement marker so completed batches count once. These data are not stored in Chrome Sync. The latest job/selection is replaced by later activity. Trial data remain until extension data are removed; normal updates do not reset the allowance. Downloaded files remain in your download directory until you delete them.

Accounts and membership

The initial five successfully saved ZIP archives can be used without signing in. After the allowance is used, the extension shows an upgrade dialog. It opens the ShipLang service at crx.shiplang.com only when you click its sign-in or payment button. This passes the product AppId, extension ID, extension version, interface language and any locally saved account UID and membership expiry for the same product. The service receives ordinary web request metadata. The extension locally stores the returned product AppId, UID, membership expiry and optional email, avatar and name to restore access. A valid same-product membership allows use without consuming trial uses.

After sign-in, the extension configures a ShipLang uninstall-feedback URL containing the UID and extension version. Chrome visits that URL if you uninstall the extension. This URL does not include listing titles or downloaded media records.

ShipLang.com protects and retains the email, avatar and membership expiration information needed for login and membership until you request deletion. To request deletion, email support@shiplang.com, identify this extension by its name or download link and describe your request and reason. Requests are processed within seven days, with no backup retained. Removing the extension removes its Chrome local extension records but does not by itself delete a ShipLang account or downloaded files.

External login and checkout

Login and payment take place in external service windows. The extension does not read or store card numbers, bank credentials or Google passwords. If you choose Google sign-in, Google's handling of account data is described in the Google Privacy Policy. The checkout page identifies the payment processor before payment. If you choose a PayPro Global checkout, see the PayPro Global Privacy Policy; if you choose a Stripe checkout, see the Stripe Privacy Policy. These links describe the respective external services and do not imply that every payment method is available.

Permissions

  • activeTab: temporary access to the current listing after you invoke the extension.
  • scripting: run the packaged gallery-reading function in that authorized tab.
  • downloads: save one ZIP containing the selected media, inspect the download ID from the extension's own latest job, and open the downloads folder.
  • storage: retain the latest job/selection, trial allowance and account/membership state locally.
  • offscreen: prepare the ZIP and retain its local Blob URL in a hidden packaged document so closing the toolbar popup does not interrupt preparation or saving.

There are no permanent host permissions or remote executable scripts. Listing records are not sold or used for advertising, unrelated profiling or creditworthiness. The extension contains no developer analytics or advertising tracker. External sites have their own policies and network logging.
